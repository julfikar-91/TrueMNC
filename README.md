# TrueMNC – True Corporate Job Finder

> Android-only Flutter app backed by Firebase, Cloud Functions Gen 2 (TypeScript), and Gemini AI.

---

## Prerequisites

| Tool | Version |
|------|---------|
| Flutter | ≥ 3.22 (stable) |
| Dart | ≥ 3.3 |
| Node.js | 20 LTS |
| npm | ≥ 10 |
| Firebase CLI | ≥ 13.x |
| FlutterFire CLI | ≥ 1.0 |
| Android Studio / SDK | API 35 (target), API 26 (min) |

## First-Time Setup

### 1. Install global CLIs
```bash
npm install -g firebase-tools
dart pub global activate flutterfire_cli
```

### 2. Login to Firebase
```bash
firebase login
```

### 3. Create two Firebase projects
Create **dev** and **prod** projects in the [Firebase Console](https://console.firebase.google.com):
- `truemnc-dev`
- `truemnc-prod`

Then update `.firebaserc`:
```json
{
  "projects": {
    "dev": "truemnc-dev",
    "prod": "truemnc-prod",
    "default": "truemnc-dev"
  }
}
```

### 4. Configure FlutterFire (generates firebase_options.dart + google-services.json)
```bash
# Dev environment
firebase use dev
flutterfire configure \
  --project=truemnc-dev \
  --platforms=android \
  --android-package-name=com.truecorporate.jobfinder \
  --out=lib/firebase_options.dart

# This also places android/app/google-services.json automatically
```

> ⚠️ **Never commit** `lib/firebase_options.dart` or `google-services.json` to a public repo.

### 5. Install Flutter dependencies
```bash
flutter pub get
```

### 6. Run code generation (Freezed / JSON models)
```bash
dart run build_runner build --delete-conflicting-outputs
```

### 7. Install Functions dependencies
```bash
cd functions
npm install
npm run build
cd ..
```

## Running the Emulator Suite

```bash
# Start all emulators (Auth, Firestore, Functions, Storage) with UI
firebase emulators:start

# Emulator ports (defaults):
#   Auth      → http://localhost:9099
#   Firestore → http://localhost:8080
#   Functions → http://localhost:5001
#   Storage   → http://localhost:9199
#   UI        → http://localhost:4000
```

To use emulators in the Flutter app, set env flag in `main.dart` (provided as `kDebugMode` checks in the services file).

## Deploying Cloud Functions

```bash
# Deploy to dev
firebase use dev
cd functions && npm run build && cd ..
firebase deploy --only functions

# Deploy to prod
firebase use prod
firebase deploy --only functions
```

## Deploying Firestore Rules & Storage Rules

```bash
firebase deploy --only firestore:rules,storage
```

## Security Notes

- **Roles** (`USER` / `ADMIN` / `SUPER_ADMIN`) are **Firebase custom claims only** — never Firestore fields.  
  Only the `setUserRole` Cloud Function (callable by SUPER_ADMIN) can assign roles.
- **Verification status** (`isVerified`) on jobs/companies is **server-set only** — Firestore rules block client writes.
- **AI scoring** is advisory; AI never sets `isVerified`.
- **App Check** (Play Integrity in release, Debug Provider in debug) protects all Firebase calls.
- **No secrets in Flutter** — all Gemini, Admin SDK, and sensitive logic lives in Cloud Functions.
